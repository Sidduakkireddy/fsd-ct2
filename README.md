# fsd-ct2
# 👨‍💻 Student Team Members Management Application

This is a Full Stack Web Application built as part of the **FSD CT2 project** for managing team members. It allows users to add, view, and delete team members along with their profile images.

---

## 🚀 Technologies Used

### Frontend:
- React.js
- Axios
- React Router DOM
- CSS

### Backend:
- Node.js
- Express.js
- MongoDB (with Mongoose)
- Multer (for image uploads)
- CORS

## 📸 Features

- 🏠 Home Page with navigation
- ➕ Add Member with image upload
- 👥 View all members in a clean card layout
- 🔍 View individual member details
- 🗑️ Delete members
